## Quality Checklist

### Diagram Retrieval
- [ ] Attempted arch-diagrammer search in Step 1
- [ ] Recorded project details (ID, count) or noted not found
- [ ] Appendix includes diagram repository reference

### Epic Quality
- [ ] Every epic has 3-6 component diagram
- [ ] All language is business-friendly
- [ ] "What We're Building" uses plain language
- [ ] "Why It Matters" explains business value
- [ ] Dependencies list only critical blockers
- [ ] Success metrics are measurable

### Document Quality
- [ ] Overview shows team size and epic count (NO dates/timelines)
- [ ] Gantt chart uses axisFormat % (not dates)
- [ ] Gantt chart labels include TECH-EPIC-XXX identifiers
- [ ] NO "Delivery Summary" sections
- [ ] NO week estimates in epic descriptions
- [ ] Every iteration has team coverage
